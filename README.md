# 筑思 · Zhusi

> 在动手写代码前，帮你想清业务和架构。

筑思计划成为一个本地优先的 CLI + MCP + Skill 工具。AI 通过它补充需求、设计业务流程、解释架构取舍，并保存跨模型评审记录，最终生成简洁的网页报告。

**当前状态：设计阶段。仓库尚未实现 CLI、MCP 服务或网页生成器。**

- [详细设计文档](docs/design.md)
- [实施计划与验收标准](docs/roadmap.md)

## 第一版目标

1. 通过现有 AI 客户端完成设计，无需额外购买或配置模型 API。
2. 多个 AI 可以先后读取同一项目，提交可追溯的评审。
3. 默认展示简短结论，按需展开理由、替代方案和讨论记录。
4. 所有设计数据保存为本地文件，支持 Git 管理。

## 设计中的使用方式

以下命令是拟议接口，目前不能执行：

```sh
zhusi init
zhusi status --json
zhusi validate
zhusi report
zhusi mcp
```

## 与其他工具的关系

- OpenSpec：组织规格与实施任务；筑思聚焦需求澄清、架构教学和决策评审，可导出材料供其使用。
- CodeGraph：理解现有代码结构；筑思管理设计意图与决策依据，后续可在宿主 AI 中配合使用。

名称和 npm 包名尚未核查。开放仓库不等于已授予开源许可；许可证待维护者选择。
